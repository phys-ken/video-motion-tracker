# 授業当日の手引き（教員用）

配布物・URL・つまずいたときの対処をまとめたページです。生徒には配りません。

## 1. 使う URL

| 用途 | URL |
|---|---|
| 解析アプリ（生徒） | https://phys-ken.github.io/video-motion-tracker/ |
| 実験手順（生徒） | 同上 `guide/` — 自由落下 / `guide/vertical_throw.html` / `guide/projectile.html` / `guide/oblique.html` |
| 提出画像の照合（教員のみ） | 同上 `teacher/` — アプリからのリンクはありません |

QR コードは README に貼ってあります。授業前に投影用スライドへ貼っておくと配布が速いです。

## 2. 当日の流れ（想定）

1. 教員機で［サンプルで試す］→ 鉛直投げ上げ を開き、スケール設定から
   グラフまでを一度いっしょにやって見せる。
2. 生徒は自分の端末で撮影 → 解析 → ［提出用の画像を作る］→ PNG を保存 →
   Classroom / Forms に提出。
3. 提出物は `teacher/` に一括でドロップして、照合コードの重複を確認する。

## 3. 提出物の見方

画像には**打った点から作られる 8 桁の照合コード**が印字され、PNG の中にも記録されます。
同じ動画でも、タップした位置が違えばコードは必ず変わります。

- **同じコードが 2 人から出た** → 同じ打点データの使い回しです。
- **コードが読めない** → スクリーンショットや画像加工を通したもの。画像に印字された
  8 桁を目で読んで突き合わせてください。
- 提出フォームに「照合コード」欄を作っておくと、目視だけでも重複に気づけます。

## 4. つまずいたときの対処

| 症状 | 対処 |
|---|---|
| 画面が古いまま／表示が崩れる | ページを再読み込み。直らなければ Safari の履歴とデータを消してから開き直す。画面右上のバージョン表示が最新（`v2026-09-03b` 以降）かで判断できる。 |
| 「この形式の動画は開けません」 | **撮った iPad の Safari でそのまま開く**のが最短。PC に送ると HEVC で開けないことがある。撮り直せるなら 設定 > カメラ > フォーマット を「互換性優先」に。 |
| 前の人の点が残っている | 起動パネルが必ず出るので、運動の種類を選び直せばよい。自分の続きなら同じ動画を選び直すと数秒だけ［戻す］が出る。 |
| 保存した画像が見つからない | 共有シートが出た端末は「写真に保存」。出なかった端末はファイルアプリの「ダウンロード」。それでも駄目なら、画面に出ている完成画像を**長押しして「写真に追加」**。 |
| グラフが直線にならない | スケールを設定したか、コマを飛ばさずに打ったか、スローで撮っていないかを確認。 |
| Wi-Fi が不調でページが開けない | 教員機でリポジトリを開き `python3 serve.py`。同一 LAN の端末から `http://<教員機のIP>:8000` でつながる。 |
| どうしても解析できない生徒がいる | サンプル動画（鉛直投げ上げ等）で提出させる。照合コードは打点から作られるので、サンプルでも生徒ごとに違う値になる。 |

## 5. 撮影で押さえること

- スローではなく通常の「ビデオ」で撮る。
- カメラは固定。**動画は 10 秒以内**（長いと時刻の精度が落ちる）。
- ものさし（長さの分かるもの）を運動と同じ面に置き、画面に写す。
- 明るい場所で撮る。暗いとボールがブレて楕円になる。
