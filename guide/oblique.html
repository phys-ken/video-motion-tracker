物理・実験手順書（生徒用）

斜方投射の動画解析 — 山なりのボールの正体

用意するアプリ: 動画解析トラッカー（先生から配布されたURLをブラウザで開く。インストール不要）
実験手順書: 自由落下 鉛直投げ上げ 水平投射 斜方投射 解析アプリを開く ▶
今日のゴール: 斜め上に投げたテニスボールを撮影し、山なりの運動が 「水平の等速直線運動」と「鉛直の投げ上げ運動」の組み合わせで できていることを、vx–t・vy–t グラフで確かめる。

準備するもの（班ごと）

  • テニスボール
  • 1 m ものさし（または 10 cm 方眼を印刷した模造紙）
  • 撮影用の iPad または スマホ 1台、固定するもの、テープ
  • 投げる人・撮る人の2人以上で

手順 1撮影する

最重要ルール：「ビデオ」モードで撮る。スローは使わない

スロー動画は時間の情報が食い違い、加速度が数十分の一に出ます。ふつうのビデオでOK。

  1. 壁に1 m ものさしをテープでとめる（軌道と同じ面に）。
  2. カメラを横向きで固定し、壁から 3〜4 m 離れて正対。 山なりの軌道全体（投げてから着地まで、幅 2〜3 m・高さ 1〜1.5 m）が入る画角に。
  3. 録画を開始 → 壁のすぐ前で、ボールを斜め上 45° くらいに下手で軽く投げる。 投げる向きは壁と平行に（奥や手前に投げない）→ 着地まで見送って録画を止める。
  4. 強く投げすぎると画面から出る。ふわっと山なりがちょうどいい。
  5. 角度を変えて（30°・45°・60°くらい）何本か撮っておくと発展課題に使える。
撮影チェックリスト
  • スローではなく「ビデオ」で撮った／カメラ固定・横向き
  • 動画は短く（10秒以内）。長い動画は時刻の精度が落ちる。
  • 手を離れてから着地までの山全体が画面に入っている
  • 壁と平行に投げた（軌道が手前・奥にふくらんでいない）
  • ものさしが軌道と同じ面に写っている

手順 2読み込んで、前後をカット

  1. [動画を選択] で読み込む → 「読み込み完了」の画面。
  2. 手を離れた直後のコマで [ここから]、着地直前のコマで [ここまで] → [はじめる]。
「手が離れる前」を入れないこと

手が押している間は重力以外の力がはたらいている。イン点は「離れた直後」から。

手順 3スケールを決める

  1. 動画を読み込むと、そのままスケール設定に入る（オレンジの帯が出る）。
  2. 十字をものさしの片端に合わせて [確定] → もう一方の端で [確定]。
  3. 長さを cm で入力。そのままトラッキングに進む。

原点を決める操作はない。最初に打った点が原点になるので、 まず「手を離れた瞬間のボール」に点を打つ。

手順 5点を打つ

  1. 十字をボールの中心に合わせて [確定] → 自動で次のコマへ。着地まで繰り返す。
ボールに点を打つコツ（3つのルール）
  • 迷ったら拡大（2本指ピンチ）。
  • 毎回「同じ場所」を狙う（中心か、決めにくければ常に上端）。
  • 表面の模様や印は追わない（回転でニセの振動が乗る）。
  • 抜けは打点マップで確認（測定データパネル。チップをタップで移動→打ち直し）。

手順 6グラフを読む — 山なりを2つに分解する

  1. グラフの おすすめ: [投射（放物線）] を押す → y–x（軌道）・vx–t・vy–t が出る。
  2. y–x（軌道）: 自分の投げたボールの軌道。左右対称の放物線に見えるか？
  3. vx–t をタップして拡大 → ほぼ水平な直線なら水平方向は等速。 その値が v₀ₓ（＝ v₀cosθ）。
  4. vy–t をタップして拡大 → プラスから 0 を通ってマイナスへ、 1本の右下がり直線。横にドラッグして傾きを読む → −9.8 m/s² に近いか。 vy = 0 の時刻が最高点。
考えてみよう

① 最高点でボールの速度は 0 か？（vy は 0 でも vx は？ グラフで確かめる）
② vy–t のグラフは、鉛直投げ上げの実験と同じ形。つまり斜方投射の鉛直成分は何運動？
③ 上がる時間と落ちる時間、飛び出す速さと着地の速さは、それぞれ等しいか？ グラフの対称性から読み取ろう。

手順 7記録して提出する

  • [実験結果を保存] → 写真（残像）でPNG保存。横は等間隔・縦は最高点付近ほど詰まる 残像列が見えるか。「点マーカー」なら軌道の散布図としても保存できる。
  • [測定データを xlsx／TSV で出す]（画面いちばん下） → TSVコピー または xlsx 保存。
  • レポート: v₀ₓ・vy–t の傾き・最高点の時刻と高さ・軌道の対称性についての考察。

うまくいかないとき

症状原因と対処
加速度が数十分の一スローで撮っている。ビデオで撮り直す。
vx–t が右下がりになる 壁と平行に投げられていない（奥へ逸れて遠ざかっている）か、空気抵抗。 まず投げる向きを直して撮り直す。
軌道が左右非対称 手前・奥方向のふくらみ（3次元的に飛んでいる）。壁と平行に投げ直す。
ボールがブレる・見失う 明るい場所で撮り直す。投げをゆるくして速度を下げるのも有効。

提出1枚の画像にまとめる

  1. 「測定データ」の [実験結果を保存] を押す。
  2. ストロボ写真とグラフが並んだ1枚ができる（A4縦）。
  3. [PNG保存] → そのまま提出する。

画像には照合コード（8桁）が入る。自分が打った点から作られるので、 人のデータを使うと同じコードになって分かってしまう。自分でタップすることが この実験の中心。

発展課題

  • 角度 30°・45°・60° の動画を比べる: 一番遠くへ飛ぶのはどれか。 v₀ が同じなら 45° が最大になるはず — 実測で確かめる。
  • v₀ₓ と v₀ᵧ（vy–t の切片）から v₀ と角度 θ を計算し、 最高点の高さ・滞空時間の理論値を出して実測と比べる。
  • 水平投射の実験（別の手順書）と vy–t を比べる。違いは「切片」だけ？
